Four hooks, on at install

They run before Claude's commands, not after. If a hook ever errors, the command runs normally, so they can't lock you out.

bash-checkpoint

Blocks commands that wipe your home folder or a drive, asks before git push --force and reset --hard, and snapshots files before every rm, mv or git clean so you can put them back.Bash and PowerShell, Windows, macOS, Linux

package-guard

Checks every npm install and pip install against the real registries. Packages that don't exist are blocked; typosquats and days-old packages need your OK.npm and PyPI

read-guard

Stops Claude from loading a huge file whole and burning your usage limit. It points to a search or a partial read instead, and lets a repeated request through.Read, Bash, PowerShell

session-handoff

Warns when a session passes 150k tokens and writes a handoff note, so you can continue in a fresh, cheaper session without losing the thread.Runs when Claude stops

How they're built

The same rules apply to every skill.

  • No dependenciesNode's standard library only. Nothing to npm install.
  • Read-only by defaultAnything that changes files needs a flag and keeps a backup.
  • Nothing phones homeNo telemetry. Network use is listed in SECURITY.md.
  • Tested on three systemsCI runs the suites on Windows, macOS and Linux on every push.
