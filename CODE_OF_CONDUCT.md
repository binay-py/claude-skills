# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, and keep criticism about the code, not the person. Harassment, insults and personal attacks aren't accepted in issues, pull requests or discussions.

Report problems privately to the maintainer through the contact on the [GitHub profile](https://github.com/binay-py). Reports are kept confidential. The maintainer may remove comments or block accounts that break these rules.
